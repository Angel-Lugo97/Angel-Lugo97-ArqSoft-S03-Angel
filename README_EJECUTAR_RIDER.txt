CatalogoApp - Versión visual estilo Forja/Salamanders + Login + Reseñas

Cómo abrirlo en JetBrains Rider:
1. Descomprime el ZIP.
2. Abre directamente el archivo CatalogoApp.sln.
3. Si Rider pregunta qué proyecto ejecutar, selecciona CatalogoApp.Presentation.
4. Ejecuta con el perfil http.
5. Debe abrir directo en: http://localhost:5279/Catalogo

Usuario de prueba:
Correo: demo@catalogo.com
Contraseña: 1234

Funciones incluidas:
- Catálogo de videojuegos.
- Filtro por género.
- Agregar videojuego solo si el usuario inició sesión.
- Registro de usuarios.
- Inicio y cierre de sesión.
- Agregar reseñas solo si el usuario inició sesión.
- Reseñas guardadas dentro de data/items.json.
- Usuarios guardados dentro de data/usuarios.json.
- Estilos visuales reciclados del proyecto proporcionado: fondo oscuro, botones verdes/naranja, paneles, cards, navbar y formularios.

Archivos importantes:
- CatalogoApp.Presentation/Controllers/UsuariosController.cs
- CatalogoApp.Presentation/Controllers/ResenasController.cs
- CatalogoApp.Presentation/Controllers/CatalogoController.cs
- CatalogoApp.Presentation/data/items.json
- CatalogoApp.Presentation/data/usuarios.json
